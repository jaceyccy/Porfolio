Machine Learning / Robotics

Autonomous Lane-Following Robot

Developed an image-based driving model to guide a robot through autonomous lane following.

  • Trained deep-learning models using TensorFlow and recorded driving images.
  • Deployed trained models to Raspberry Pi hardware and evaluated driving behavior.
  • Explored image augmentation to address changes in lighting conditions.
  • Python
  • TensorFlow
  • Raspberry Pi

Data Analysis / Predictive Modeling

Recipe Analysis & Predictive Modeling

Investigated recipe characteristics through data cleaning, statistical analysis, and predictive modeling.

  • Cleaned recipe data and analyzed missingness to assess data quality.
  • Applied permutation tests and hypothesis testing to investigate patterns.
  • Built a predictive model and published findings in a project website.
  • pandas
  • Statistical Testing
  • Machine Learning
